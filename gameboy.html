Game Boy

The Nintendo Game Boy was the first Nintendo handheld game console. The Game Boy was released in America in July 1989. Nintendo created the Game Boy to be like a home console with interchangeable game cartridges, except portable. The device features a dot-matrix display, a directional pad (d-pad), four game buttons (an A button, a B button, a Start button, and a Select button,), a single speaker, and uses Game Pak cartridges. Despite its monochrome graphics and larger size compared to other handheld consoles, it quickly outsold competitors (an estimated 118.69 million copies of it and the Game Boy Color were sold) due to the selection of Nintendo games anywhere you want.
